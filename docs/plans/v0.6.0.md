# Version 0.6.0 plan — help and feedback foundation

Version 0.6.0 adds a visible, privacy-first path from the plugin to the project's public support channels. It does not add telemetry, automatic diagnostic submission, a hosted backend, or runtime command authority.

## Shipped outcomes

- A shared Help and feedback modal opened from settings or the command palette.
- Explicit routing for bugs, compatibility problems, ideas, questions, documentation, and private vulnerability reports.
- An on-demand diagnostics preview built from an allowlist of versions, health states, aggregate counts, and relevant settings.
- An explicit clipboard action with no persistence or automatic transmission.
- GitHub issue forms, Discussions routing, support documentation, and release checks that keep those surfaces consistent.

## Privacy contract

Diagnostics exclude paths, identifiers, titles, terminal previews, transcripts, task content, notifications, raw errors, environment variables, and secrets. Constructing the preview does not refresh cmux, inspect provider files, scan the vault, or make a network request.

## Release gates

- Exact diagnostics allowlist and forbidden-value regression tests pass.
- Settings and command-palette entry points open the same modal.
- Clipboard failures remain visible and plugin unload produces no late UI effects.
- Every external destination is fixed, HTTPS-only, and verified against the repository support configuration.
- The complete release and vault-local support checklist passes before tagging 0.6.0.
